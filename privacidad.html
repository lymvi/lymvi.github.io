Política de privacidad

myHome HA es una instalación privada de Home Assistant que usa una sola familia en su propio servidor doméstico.

  • Qué datos: el estado de los dispositivos de la cuenta de Google del propietario (termostatos, altavoces) y las órdenes que él mismo envía.
  • Dónde: solo en el servidor doméstico del propietario. No se envían a terceros, no se venden y no se usan para publicidad.
  • Quién: nadie más que el propietario tiene acceso. No hay usuarios externos.
  • Borrado: el propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions; al borrar la integración se eliminan sus datos.

El uso de la información recibida de las API de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado.

Private, single-household app. Data from Google APIs stays on the owner's own server, is never shared, sold or used for ads, and complies with the Google API Services User Data Policy, including the Limited Use requirements.
