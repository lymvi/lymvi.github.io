myHome HA

Instalación privada de Home Assistant de una sola familia. Usa las API de Google (Smart Device Management y Google Assistant) solo para controlar los dispositivos de su propia cuenta desde su propio servidor.

No es un servicio público: no tiene usuarios externos ni registro.

Private, single-household Home Assistant instance. It uses Google APIs only to control the owner's own devices from the owner's own server. Not a public service.
